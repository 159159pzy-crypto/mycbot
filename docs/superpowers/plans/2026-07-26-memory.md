# Memory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver Milestone 5 of the roadmap: durable, scoped, revocable memory that measurably improves replies. The bot extracts candidate memories after agent turns, retrieves them by scope + similarity into the prompt under a dedicated token budget, enforces privacy in code (never in the prompt), honors a user-visible `/forget` command, and ages memories out via the maintenance worker's first real job.

**Architecture:** An `EmbeddingClient` speaks the OpenAI-compatible `/embeddings` protocol (falling back to the LLM endpoint credentials). Migration 0005 creates `memory_items`, mapping every field of the frozen `MemoryItem` contract plus a dimensionless pgvector `embedding` column tagged with its `embedding_model`, so retrieval always compares vectors from one model and model switches degrade gracefully instead of erroring. A `MemoryRepository` owns storage, cosine search with scope/privacy/validity filters, revocation, and lifecycle passes (expire → decay → cleanup) with injected clocks. A `MemoryService` composes policy: retrieval renders a provenance-marked context block for the agent under `MYBOT_MEMORY_TOKEN_BUDGET`; extraction asks the LLM for strict-JSON candidates post-turn, applies confidence thresholds and scope inference, and can never produce SENSITIVE items. The engine gains two thin hooks (a second system message before the tool loop; `after_reply` extraction), the worker gains `/forget`, and the maintenance worker runs the lifecycle pass on an interval.

**Tech Stack:** Python 3.12, pgvector (dimensionless column, exact cosine scan), httpx, Pydantic v2, SQLAlchemy async, Alembic, Pytest.

## File map

- `src/mybot/infrastructure/embeddings.py`: OpenAI-compatible embeddings client.
- `src/mybot/engine/memory_service.py`: retrieval block rendering, privacy policy, extraction policy.
- `src/mybot/engine/agent_turns.py`: memory hooks (`retrieval` before the tool loop, `after_reply` extraction).
- `src/mybot/services/agent_worker.py`: `/forget` command, `after_reply` dispatch, memory wiring.
- `src/mybot/services/maintenance.py`: periodic expire/decay/cleanup lifecycle service.
- `src/mybot/settings.py`, `compose.yaml`, `.env.example`, `README.md`: embedding endpoint and memory knobs.

**Not in this milestone:** memory as an agent-visible tool, a memory browsing API/UI (M7), cross-conversation SHARED memory surfacing, embedding backfill jobs after model switches, and ANN indexes (exact scan is fine at personal-bot scale; an HNSW index can be added once embedding dimensions are pinned).
